# VRC-Avatar-Kiosk
Allows you to have a Kiosk in your world that uses a secret gist so you can Add or Remove Avatars without updating the world


Make a Secret Gist .txt (if you dont know what that is search it up)

Add an Avi (Or a bunch)

Click the Raw Button

Edit the URL to remove the text between raw/ and /gist name.

If done correctly you can hit enter and view that URL like nothing happened, This is to remove the version so you can update it without having to re enter the URL to the System.

All Avis are listed in Order not sorted, Folders work correctly, Descriptions are custom because you cant read that from a Avi Pedestal (They are not requred), The PFP of the Avi Displayed is the Pedestal itself, Follow formatting bellow and you should be good, DM me for help on discord. cameraguy

(Folder Path Optional)/(Avatar Name) : (Avatar ID) | (Description)

Exsample

Halo/ODST/Alpha Nine/Old/Dare : avtr_**** | An old Relic.

Avatars that only appear for a certain person can be done like

Custom/_usr (User Name Not ID)/(Folder Path Optional)/(Avatar Name) : (Avatar ID) | (Description)

Exsample

Custom/_usr Camera-Guy/R6/Master Chief : avtr_**** | This game looks potato compared to launch
